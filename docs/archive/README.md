# Archivo histórico (no vigente)

`articulos-lft-legacy.ts.txt` conserva sin modificaciones el antiguo conjunto de datos de `src/data/articulos-lft.ts`, retirado del código de aplicación porque no tenía consumidores y duplicaba contenido editorial.

**No es una transcripción oficial ni una fuente vigente.** Incluye referencias antiguas, resúmenes y atribuciones incorrectas (por ejemplo, mezcla contenido de los artículos 24/26, 83/84, 85/86, 67/68 y 70/71). No importar, publicar ni reutilizar sus textos como asesoría.

La fuente de la biblioteca educativa y de sus detalles locales es [articleDetails.ts](../../src/data/articleDetails.ts). Para artículos no incluidos o para consultar el texto legal completo, usar la [LFT oficial de la Cámara de Diputados](https://www.diputados.gob.mx/LeyesBiblio/pdf/LFT.pdf).

La conservación histórica no implica revisión de las entradas ni resuelve por sí sola el issue #64.
